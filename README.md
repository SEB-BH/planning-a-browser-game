## About

Before we start coding, we need a clear plan for what we will build.

Today, we will decide what our game needs to do, sketch its main screen, and organize our work.

By the end, you will have:

- **10 user stories** describing your game’s features.
- **One wireframe** created in Excalidraw.
- **One GitHub Projects board** linked to your project repository.
- A small selection of stories for your first sprint.
